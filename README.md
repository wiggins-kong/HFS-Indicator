# HFS 状态托盘

在 Windows 通知区放一只抱文件的海鸥，右下角一盏小状态灯，用来**看 HFS 是不是在跑**、**一键暂停/恢复**、**直接打开前台和后台页面**。

它不是一个文件服务器，也不替代 HFS。HFS 该怎么装还怎么装，这个程序只是它的遥控器和状态灯。

```text
HFS 运行中 · 192.168.3.5:1478 · 2 连接     ← 灰字，不可点
────────────────────────
打开前台页面
打开后台管理
复制局域网链接
────────────────────────
暂停服务            ← 停止时变成「启动服务」
重启服务            ← 只在运行中可点
────────────────────────
✓ 开机自启
────────────────────────
退出
```

左键单击图标 = 打开前台页面；右键 = 上面的菜单。

## 前置条件

- HFS 已经作为 **Windows 服务**运行（本机服务名 `HFS`）。托盘靠这个服务来暂停和启动 HFS。
- 装有 **.NET 10 桌面运行时**。没装的话，双击 exe 会弹一个英文提示框，点"是"会跳到微软官方下载页，装完再双击即可。

## 开始使用

1. 把 `HfsIndicator.exe` 放进一个**只有你能写**的目录，例如 `D:\Programs\HfsIndicator\`。不要放在共享目录或 `C:\Users\Public`，因为它以管理员权限运行。
2. 双击它。通知区出现一个海鸥图标，没有窗口，任务栏也不会有东西。
3. 想让它每次开机都出现，右键 → 勾选 **开机自启**。

## 图标颜色

| 颜色 | 含义 | 你该做什么 |
| --- | --- | --- |
| 🟢 绿 | 运行中，页面可访问 | 什么都不用做 |
| 🟡 黄 | 正在启动或正在停止 | 等一两秒 |
| ⚪ 灰 | 已暂停（服务已停止） | 菜单里点「启动服务」 |
| 🔴 红 | 服务在跑但页面打不开，或找不到服务 | 点「重启服务」；反复出现就去看 HFS 日志 |

## 开机自启

- 勾选 = 在当前用户的启动文件夹里放一个 `HFS 状态托盘.lnk`，指向你**现在正在运行的这个 exe**。取消勾选 = 删掉它。
- 你把 exe 挪了位置，下次打开会发现勾没了——因为旧快捷方式指向一个不存在的地方。重新勾一下，它会就地覆盖成新路径。
- 这是托盘自己的自启，跟 HFS 服务的开机自启是两码事，互不影响。

## 可选配置

默认就找服务名 `HFS`、端口 `1478`。换到别的机器、名字不一样时，**手动**在 exe 旁边建一个 `HfsIndicator.json`：

```json
{
  "serviceName": "HFS",
  "port": 1478
}
```

两个字段都可以只写一个，缺的用默认值。

> **程序只会读这个文件，永远不会自己生成、修改或删除它。** 如果目录里没有它，就用默认值运行；你删掉它，行为回到默认。

## 常见问题

**通知区里没看到海鸥。**
Windows 11 默认把新出现的托盘图标收进「显示隐藏的图标」（任务栏上的 `^`）。点开那个面板，把海鸥拖到任务栏上，以后就一直显示了。

**双击了，但什么也没出现。**
可能已经有一个在跑了——它只允许一个实例，重复双击只会弹一个提示气泡。也可能 UAC 的"否"被点了（默认设置下不会弹框）。

**图标是灰的。**
HFS 服务当前是停止状态，也就是你之前点过「暂停服务」。点「启动服务」。

**图标是红的，写着"运行中但无响应"。**
服务进程还在，但 1478 端口没回应。点「重启服务」。如果一直这样，去看 `D:\Programs\hfs\logs\`。

**右键里没有「暂停服务」，只有灰字"未找到 HFS 服务"。**
服务名不是 `HFS`，或者 HFS 根本不是以服务方式装的。用上面的 `HfsIndicator.json` 指定 `serviceName`；如果 HFS 是普通程序，这个托盘只能当状态灯。

**复制出来的链接，跟 HFS 后台里显示的不一样。**
托盘用的是 HFS 实时检测到的局域网地址；HFS 后台那个 `base_url` 是手填的，可能已经过期。以托盘复制的为准。

**换到另一台电脑。**
对方也得把 HFS 装成 Windows 服务，并装 .NET 10 桌面运行时；服务名/端口不一样就加 `HfsIndicator.json`。

## 卸载

1. 右键图标 → 取消勾选 **开机自启**（或手动删掉启动文件夹里的 `HFS 状态托盘.lnk`）。
2. 右键图标 → **退出**。
3. 删掉 `HfsIndicator.exe`，以及你自己建过的 `HfsIndicator.json`。

HFS 服务、配置、共享目录都不受影响。
